The theme is one app, crud_views_tabler, listed before crud_views in INSTALLED_APPS. Its templates shadow django-crud-views’ stock Bootstrap 5 templates of the same name, and whatever it does not override falls through. Button classes, icons and the JavaScript adapters are registered through upstream hooks in apps.py; no crud_views code is patched or subclassed. The sales, catalog, roastery and shipping apps never import it: open {% icon "code" "icon-sm me-1" %}Show code on any of their pages to check.
